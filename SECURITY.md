# Security

Report suspected vulnerabilities privately through [Glowing Coders](https://glowingcoders.com/). Do not post working exploits, credentials, private snippet content or site database exports in public GitHub issues.

Include the affected plugin/WordPress/PHP versions, a concise description, required permissions and reproducible steps using harmless example content. Known exploitable issues block a public release.

Version 1.0.0 manages HTML and plain text only. It has no user-code execution path or external installer/updater. Security testing does not replace independent review. See [security and recovery](docs/security-and-recovery.md) for the exact content, access and migration boundaries.
