# Security policy

0.1.0 is a development build. Do not use it for untrusted authors or on production before staging verification and a reviewed release.

Please report vulnerabilities privately using this repository's **Security > Report a vulnerability** feature if available. If private reporting is unavailable, contact the maintainer through [Glowing Coders](https://glowingcoders.com/) to arrange a private channel. Do not post exploit code, credentials or customer snippet source in a public issue.

The trust boundary, recovery steps and known limitations are documented in [Security and recovery](docs/security-and-recovery.md). There is no claim of a security audit, sandbox or vulnerability-free software. Known exploitable vulnerabilities block a public release.

No Composer or npm packages are shipped in the installation archive. Development dependencies are locked and checked separately. Customer update delivery is not implemented in this version.
